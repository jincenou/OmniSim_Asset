This repository organizes project integration code and historical experiment
scripts. Original file notices remain applicable. Model weights, datasets,
body-model files, third-party checkout trees and generated assets are excluded.

The source snapshot includes project-specific adaptations and files derived from
earlier project integrations. This publication does not relicense third-party
code or grant rights to excluded datasets or models. See
[dependency sources](docs/DEPENDENCIES.md) and the preserved source notices.

`provenance/source_manifest.json` records the original relative path, byte length
and SHA256 of every collected source file. The static checks performed for this
release are distinct from GPU experiment or output-quality validation.
